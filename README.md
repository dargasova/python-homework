# Практические работы по Python

Автор: Аргасова Диана Владимировна

Репозиторий содержит семь учебных программ, демонстрирующих основные конструкции языка Python.

## Состав репозитория

| Папка | Работа | Основные темы |
|---|---|---|
| `task_01` | Инфраструктура | запуск Python-программы, переменные, вывод |
| `task_02` | Список покупок | строки, списки, методы списков |
| `task_03` | Приёмная комиссия | условия, цикл `while`, счётчики |
| `task_04` | Журнал тренера | циклы `for`, `range`, вложенные циклы |
| `task_05` | Кинофестиваль | словари, множества, обработка строк |
| `task_06` | Касса магазина | функции, списки, кортежи, словари и множества |
| `task_07` | Книжный магазин | файлы, обработка исключений, функции, словари и кортежи |

## Требования

- Python 3.12 или более новая версия Python 3;
- дополнительные библиотеки не требуются.

## Запуск

Каждая работа запускается отдельно из корня репозитория. Например:

```powershell
python .\task_02\main.py
```

Программы работают интерактивно: необходимые данные вводятся в терминале по появляющимся подсказкам.
